# DESIGN.md — Portfolio 3.0 design system

The design system for Vignesh's portfolio. It's extracted from Figma file `rGKG8uncSDJD3mYYD4UTiB` and grows as the site is built. There was no system before this; the Figma homepage is the seed.

This file is the index. Detail lives in four branches:

| Branch | Contents | Update when |
|---|---|---|
| [`design/tokens.md`](design/tokens.md) | Primitive + semantic tokens, the Tailwind v4 `@theme`, motion constants, breakpoints | A new value appears in Figma, or a decision needs one |
| [`design/components.md`](design/components.md) | Every component: Figma node, anatomy, variants, states, tokens, status | A component is built or changed |
| [`design/layout-and-motion.md`](design/layout-and-motion.md) | Page grids per breakpoint, project wheel, intro choreography, drawer, sheet, reduced motion | A layout or interaction is built or changed |
| [`design/rules.md`](design/rules.md) | Principles, do/don't, accessibility, performance, media, copy, content states, SEO | A decision is made that Figma doesn't cover |

## Character

Quiet, editorial, monochrome. Grey-scale chrome so the **project covers carry the colour**. One typeface (General Sans), two weights. Generous whitespace. The homepage is a three-column composition: who (left), the work (centre), the index (right).

## Token architecture

1. **Primitive**: raw values named by what they are (`--gray-700`). Plain `:root` properties, **no Tailwind utilities**.
2. **Semantic**: named by role (`fg-secondary`, `surface-page`, `rounded-card`). Defined in Tailwind `@theme`, so they're the only utilities that exist. **Components use only this tier.**
3. **Component** tokens only when a component varies a value per variant.

Figma names map to primitives: `gray/700` → `--gray-700`; `Heading/H4` → `text-h4`.
